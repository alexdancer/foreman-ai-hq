# Planning Chat design history

This initiative's pre-proposal map is complete. Its original assumptions that
Planning Chat would be an additional intake route, route orchestration through
the Harness Proxy, persist a repo Spec, and delegate investigation to Scout
Tasks were superseded during implementation.

Current product language lives in `CONTEXT.md`; current contracts live in the
canonical OpenSpec specifications for `planning-conversation`,
`planning-chat-ui`, `markdown-task-intake`, and `orchestrator-runtime`.
ADR-0009 through ADR-0011 preserve the relevant decision history.
